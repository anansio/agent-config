# Global Rules

These rules apply to every task, in every project.

## Language

- Write rules, skills, and reference documents in English. English is more
  precise and stays portable across tools.
- Answer the user in German. Match the language the user writes in for chat.
- Write code, code comments, commit messages, and project documentation in
  English.

## Documentation of intent

State decisions and their reasons as they are. Do not leave in notes that only
made sense during a discussion.

## Definition of done

A change is done when it is complete, secure, and covered by tests. Do not
deliver code that is untested, or code that introduces a known security risk.
