# Security

This project is small and has a small attack surface: a plugin manifest, a few
skill files, and a standard-library MCP tool server. If you find a problem, we
would still like to hear about it.

## Reporting a vulnerability

Please report security issues privately through GitHub, using the
**Report a vulnerability** button on the repository's Security tab (GitHub
Private Vulnerability Reporting). This keeps the details out of public view
until a fix is ready.

When you report, it helps to include:

- what the issue is and where it is,
- how to reproduce it,
- the impact you think it has.

You can expect an acknowledgement within a few days. Once a fix is out, we are
happy to credit you in the release notes if you would like.

## Supported versions

This is a personal project maintained on a best-effort basis. Fixes go into the
latest release; older versions are not maintained.
